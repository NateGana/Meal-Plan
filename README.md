# MealPlan

## Description
MealPlan is a simple, professional meal planning and grocery list application. It helps users organize breakfast, lunch, dinner, and snacks across the week, attach ingredients to each meal, and automatically build a grocery checklist to track what's been purchased.

## Features
- Weekly meal planner organized by day and meal type (Breakfast, Lunch, Dinner, Snack)
- Add, edit, delete, and search meals; filter by meal type
- Dashboard showing planned meals, meals this week, and today's meals at a glance
- Grocery list with quantity, category, and purchased status
- Add, edit, delete, search, and filter grocery items by category
- Mark items as purchased/unpurchased with a live progress bar
- Toast notifications for every action
- Data persists after refresh using LocalStorage
- Responsive, mobile-friendly layout with a collapsible sidebar
- Sample meals and grocery items included on first launch

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
No installation or build steps needed. Simply open `index.html` in any modern web browser.
